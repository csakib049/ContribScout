# Brag Plan: ContribScout

## What is this app?
ContribScout helps developers discover open-source GitHub repositories and open issues, with difficulty tags that help them choose a comfortable place to start.

## The angle
Turn the noisy, tab-filled search for a first contribution into one clear path: browse, choose by difficulty, inspect the issue and code structure, then continue on GitHub. The motion begins scattered and resolves into ContribScout's precise dark interface, cyan search, and recognizable difficulty colors. Keep the tone confident and useful; no inflated promises about what an issue tag guarantees.

## Hook (first 2-3 seconds)
Repository names and browser tabs crowd the frame while the line lands: “You want to contribute. Where do you start?” The clutter snaps into a single search field.

## Key moments (the middle)
- Explore screen: type a query and let real-looking repository cards settle into a tidy catalog.
- Beginner / Intermediate / Advanced filters light up in the product's green, amber, and red; select a level.
- Open a repository detail view with its issue list and file tree side by side; filter issues, bookmark the repo, then point toward GitHub.

## Outro / punchline
One last interface click; the product mark resolves beside “Your next contribution starts here.” End on “ContribScout” and “Start exploring.”

## User flow worth showing
Explore or search repositories → choose one using its difficulty tag → inspect open issues and the file tree → bookmark it or continue to GitHub.

## Tone
- Preset: polished
- Creative direction: a considered, modern product film that makes open-source discovery feel approachable and concrete
- Interpretation: restrained, deliberate motion with readable type, crisp interface details, and one clear action per beat.

## Format: landscape — 1920x1080
## Duration: 20.2 seconds

## Visual identity (from the project)
- Background: `#0a0a0a`
- Accent: `#06b6d4` (cyan), with the existing blue `#2563eb` for the CTA gradient
- Text: `#fafafa`
- Display font: Quicksand
- Body font: Quicksand, with a system sans fallback
- Strongest visual element: the dark repository catalog with cyan details and Beginner / Intermediate / Advanced badges
- Product source: the Explore and repository-detail React pages; use fictional signed-out chrome and plausible public repository examples. Do not show personal usernames, account avatars, emails, or private data.

## Share copy (draft)
ContribScout makes it easier to find an open-source project and issue that fit where you are today.

## Audio direction
- Role: polished, upbeat bed with restrained interface accents
- Music: bundled `happy-beats-business-moves-vol-12-by-ende-dot-app.mp3`, warm and steady
- Music treatment: start at 0s around 0.30 volume, bring it in smoothly, then fade under the final logo over the last second.
- Music cue guidance: bundled preset `happy-beats-business-moves-vol-12-by-ende-dot-app.music-cues.md` (about 110 BPM); favor the strong cues at 8.74s for the catalog reveal and 17.47s for the final brand beat. Treat the beat grid as guidance, not a reason to rush text.
- Audio-reactive treatment: subtle, if supported; let the existing cyan glow breathe gently with the bed. No waveform or strobing.
- SFX posture: sparse and soft; a light click for filter/search actions and a restrained impact for the brand reveal.
- Audio-coupled moments: typed search, selected difficulty chip, bookmark action, final mark reveal.
- Restraint rule: no voiceover, no loud impacts, and no sound on every card.

## Storyboard

### Scene 1 — The search — 3.2s
The frame starts with a composed field of floating repo names and tiny tab-like slivers, not a generic dashboard. They jostle briefly, then pull toward one cyan-outlined search bar as “You want to contribute. Where do you start?” settles large and legibly. The search becomes the bridge into the product.
Sequential/interaction: yes — repo fragments gather into the search field; a cursor types a short query.
Audio intent: brief, soft texture resolves into a clean UI click.
Audio-coupled idea: type the short query with a few quiet key sounds, not one sound per character.
Music: warm, steady bed begins low.
Transition mood: precise push / clean reveal → Scene 2

### Scene 2 — A clearer starting point — 3.0s
ContribScout's mark and wordmark arrive with the exact hero promise, “Find open-source projects you can actually contribute to.” The atmosphere remains dark and branded; the reveal is the only large light bloom.
Sequential/interaction: yes — mark, wordmark, and headline arrive in that hierarchy and hold long enough to read.
Audio intent: warm, confident reveal without a heavy trailer hit.
Audio-coupled idea: one soft impact lands with the mark.
Music: continues under the reveal.
Transition mood: soft crossfade → Scene 3

### Scene 3 — Choose your level — 4.5s
Recreate the real Explore experience as a framed browser view: search field, repository cards, stars/language details kept secondary, and three unmistakable difficulty filters. A cursor selects Beginner; matching cards remain clear. Use plausible repository examples and never show a signed-in username.
Sequential/interaction: yes — cards arrive in a short stagger, then the Beginner filter is selected.
Audio intent: light, tactile interface feedback.
Audio-coupled idea: two quiet card arrivals and one filter click; keep readable text on screen after the motion.
Music: steady bed; the catalog arrival may lean toward the 8.74s cue.
Transition mood: horizontal slide → Scene 4

### Scene 4 — Inspect before you jump in — 5.5s
The selected repository opens into the real product pattern: a compact repo header, open issues on the left, and a searchable file tree on the right. A short issue query narrows the list; one issue retains its difficulty badge. The viewer sees enough of the code structure to understand what they would be taking on.
Sequential/interaction: yes — detail view opens, issue query types, then the file tree expands one folder.
Audio intent: quiet, precise action sounds; the screen remains calm and legible.
Audio-coupled idea: one typing accent, a soft folder-open sound, then let the music carry.
Music: warm bed, no dramatic rise.
Transition mood: clean push → Scene 5

### Scene 5 — Take the next step — 4.0s
A bookmark fills with the product's amber accent; the app view eases back to the ContribScout mark. “Your next contribution starts here.” holds above “Start exploring.” Finish on a dark, branded frame with cyan and blue accents.
Sequential/interaction: yes — bookmark click, mark resolves, final line holds.
Audio intent: small completion cue, then a natural musical fade.
Audio-coupled idea: click at bookmark; soft payoff at the logo.
Music: fade down over the final second.
Transition mood: soft resolve → end

**Music mood for this video:** warm, polished, lightly upbeat.
**Audio summary:** a gentle modern bed supports three restrained UI actions and resolves cleanly with the brand; no narration.
